# 🚀 دليل توليد بيانات الاختبار (Seed Database)

## 📋 نظرة عامة

تم إنشاء سكريبت شامل لتوليد بيانات اختبار احترافية وعملية يمكنك استخدامها لإكمال التنفيذ في مشروعك. السكريبت يوفر:

✅ **حساب مسؤول واحد**
✅ **5 فئات منتجات** (ملابس، إلكترونيات، رياضة، عناية شخصية، منزل)
✅ **5 ماركات شهيرة** (Nike, Adidas, Apple, Samsung, Puma)
✅ **10 منتجات مع متغيرات** (Colors, Sizes)
✅ **5 مستخدمين اختبار**
✅ **4 كوبونات عروض** (نسبة، ثابت، شحن مجاني)
✅ **15 طلب عينة** بحالات مختلفة

---

## 🛠️ التثبيت والتنفيذ

### 1️⃣ تأكد من اتصال قاعدة البيانات

تأكد من ملف `.env` الخاص بك يحتوي على:
```env
MONGO_URI=mongodb+srv://your_username:your_password@cluster.mongodb.net/ecommerce
```

### 2️⃣ تثبيت Dependencies (إذا لم تكن مثبتة)

```bash
cd backend
npm install
```

### 3️⃣ تنفيذ السكريبت

**للتنفيذ الأول (تشغيل الخادم + السكريبت):**

```bash
npm run seed:all
```

أو بديل:
```bash
npm run seed:full
```

## 🔄 تشغيل السكريبت مرة أخرى

**ملاحظة مهمة:** السكريبت يتحقق من وجود البيانات قبل الإنشاء. إذا كانت البيانات موجودة بالفعل، فسيتخطى خطوة الإنشاء.

### لتنظيف البيانات وإعادة الإنشاء:

```bash
# إذا كنت تريد حذف جميع البيانات أولاً (احذر!)
# في MongoDB Compass أو من خلال MongoDB CLI:
db.dropDatabase()

# ثم شغل السكريبت مرة أخرى
npm run seed:all
```

## 🧪 الاختبار الفوري

cd admin-panel

### 2. اختبار واجهة العميل
```bash
cd customer-frontend
npm run dev
# سجل الدخول بأي حساب:
# ahmed@example.com / user123456
```

### 3. اختبار API مباشرة
```bash
# سجل الدخول
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@example.com",
    "password": "admin123456"
  }'

# احصل على المنتجات
curl http://localhost:5000/api/products

# احصل على الطلبات
curl http://localhost:5000/api/orders \
  -H "Authorization: Bearer <your_token>"
```

## ⚠️ ملاحظات مهمة

1. **تغيير كلمات المرور:** تغيير كلمات المرور الاختبار الافتراضية قبل النشر
2. **الصور:** الصور الحالية هي placeholder - يمكنك تحديثها بصور حقيقية
3. **الأسعار:** الأسعار بالدينار الجزائري (DA)
4. **التواريخ:** تواريخ الكوبونات محددة لـ 30-60 يوم من اليوم الحالي
5. **البيانات العشوائية:** بيانات بعض الطلبات تُنشأ عشوائياً لمحاكاة سيناريوهات حقيقية

## 🆘 حل المشاكل

### المشكلة: "Connection timeout"
**الحل:** تأكد من اتصالك بالإنترنت وأن MongoDB عنوان الخادم صحيح

### المشكلة: "Duplicate key error"
**الحل:** قد تكون البيانات موجودة بالفعل. حاول حذف قاعدة البيانات أو التحقق من القيود الفريدة

### المشكلة: "Type errors" في TypeScript
**الحل:** تأكد من تثبيت جميع المكتبات:
```bash
npm install
```
