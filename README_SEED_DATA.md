## ❓ الأسئلة الشائعة

### س: هل يمكن تشغيل السكريبت عدة مرات؟
**ج:** نعم، آمن تماماً. السكريبت يتحقق من البيانات الموجودة أولاً.

### س: كيف أحذف البيانات وأعيد التشغيل؟
**ج:** احذف قاعدة البيانات في MongoDB ثم شغل السكريبت مرة أخرى.

### س: هل البيانات حقيقية؟
**ج:** نعم، بيانات واقعية وعملية مناسبة للاختبار الفعلي.

### س: كم وقت التشغيل؟
**ج:** حوالي 10-30 ثانية حسب سرعة الاتصال بقاعدة البيانات.

### س: ماذا لو حدثت مشكلة أثناء التشغيل؟
**ج:** تحقق من ملف `.env` وتأكد من اتصال MongoDB.

## 🛠️ حل المشاكل

### المشكلة: "Cannot find module"
```bash
npm install
```

### المشكلة: "MongoDB connection timeout"
- تأكد من عنوان MONGO_URI صحيح
- تأكد من الاتصال بالإنترنت

### المشكلة: "Duplicate key error"
- السكريبت يتخطى البيانات الموجودة
- إذا استمرت المشكلة، احذف قاعدة البيانات
